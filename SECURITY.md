# Security Policy

This policy applies to every repository in the [`shata-solutions`](https://github.com/shata-solutions)
organization and to the products published at [shatasolutions.com](https://www.shatasolutions.com).
Because this `.github` repository is public, GitHub shows this file for any repository
that does not ship its own `SECURITY.md`.

## Reporting a vulnerability

**Please do not open a public issue for a security vulnerability.**

Report it privately to **[info@shatasolutions.com](mailto:info@shatasolutions.com)** with
the subject line `Security report`, including:

- the affected product, URL or repository and, if known, the file or endpoint;
- steps to reproduce, or a proof of concept;
- the impact as you understand it.

## What to expect

- Acknowledgement within **3 business days**.
- An initial assessment (severity, confirmed or not) within **7 business days**.
- A fix timeline once severity is assessed. Critical or actively exploited issues are
  handled immediately.

## Scope

In scope: Shata-owned code, services and products. Third-party dependencies should be
reported to their maintainers as well; if a Shata product is affected by an upstream
issue, report it here too so it can be tracked on our side.

## Supported versions

Shata products are continuously delivered. The version running in production is the
supported version unless a repository's own `SECURITY.md` says otherwise.
