# shata-solutions/.github

The public face of the [Shata Solutions](https://www.shatasolutions.com) GitHub organization.

| Path | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The organization profile shown at [github.com/shata-solutions](https://github.com/shata-solutions) |
| [`profile/assets/`](profile/assets/) | Images used by the profile: hero (light and dark) and captures of public product pages |
| [`SECURITY.md`](SECURITY.md) | Organization-wide default security policy |

This repository is public. Never place private source, internal URLs, credentials or
unpublished product information here. Assets are generated from the brand system in the
private Engineering OS repository (`brand/engineered-intelligence/`); product statuses
must match what [shatasolutions.com](https://www.shatasolutions.com) publishes.
