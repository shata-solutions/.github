# Support

Shata Solutions products are commercial and their source code is private, so support
runs through the company rather than through public issues.

| You are | Contact |
| --- | --- |
| A customer or pilot using a Shata product | [support@shatasolutions.com](mailto:support@shatasolutions.com) — include the product, your organization and what you were doing |
| Interested in a product, pilot or partnership | [sales@shatasolutions.com](mailto:sales@shatasolutions.com) |
| Reporting a security vulnerability | Follow [SECURITY.md](SECURITY.md) — never a public issue |
| Using the open-source [`engineering-os-tools`](https://github.com/shata-solutions/engineering-os-tools) | Open an issue in that repository |
| Anything else | [info@shatasolutions.com](mailto:info@shatasolutions.com) |

Product pages, live demos and status for every product are on
[shatasolutions.com](https://www.shatasolutions.com).
